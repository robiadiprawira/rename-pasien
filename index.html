Rename File Pasien

Semua proses berjalan di komputer ini. Tidak ada data yang dikirim ke internet atau disimpan di server.

1 PDF referensi

PDF berisi daftar pasien (No Kunjungan dan Nama). Nomor urut diambil dari urutan baris, dari atas ke bawah. PDF hasil scan juga bisa dibaca (dengan OCR).

Cek pembacaan kolom

Pastikan setiap kolom diberi peran yang benar. Kalau salah, ubah lewat menu di atas kolom.

Data pasien yang terbaca

Bisa dikoreksi langsung: klik isian lalu ubah. Kotak merah menandakan nilai yang mencurigakan.

Lihat PDF asli (untuk mencocokkan dengan tabel)

2 File pasien yang akan di-rename

Nama file harus berisi nama pasien, misalnya Budi Santoso.pdf. Boleh pilih banyak file sekaligus.
